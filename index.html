Security for AI

소프트웨어의 취약점을 분석하는 등 보안 작업을 수행하는 AI 에이전트 시스템을 개발합니다.
그리고 AI 에이전트를 안전하게 활용할 수 있도록 AI 에이전트 시스템 자체의 보안을 연구합니다. We develop AI agent systems that perform security tasks, such as analyzing software vulnerabilities.
We also study the security of AI agent systems themselves to enable their safe use.

연구실 소개About the Lab

보안 작업을 수행하는 에이전트와
에이전트를 안전하게 활용하는 방법을 연구합니다 Developing agents for security tasks
and studying how to use them safely

AI Security Lab은 명지대학교 김현준 교수의 연구실입니다. AI를 활용한 소프트웨어 분석과 에이전트 보안을 연구하며, 세부 주제로 AI 기반 바이너리 분석을 다룹니다. 김현준 교수가 공동 교신저자로 참여한 CyBiasBench에서는 사이버 공격 시나리오에서 LLM 에이전트의 행동 편향과 작업 수행 성능을 분석했습니다. Led by Prof. Hyunjun Kim at Myongji University, our lab studies AI-based software analysis and agent security, with binary analysis as a specific research topic. CyBiasBench, with Prof. Kim as a co-corresponding author, examines behavioral bias and task performance in LLM agents across cyber-attack scenarios.

주요 연구 주제Research Topics

AI for Security

AI 기반 소프트웨어 분석과 보안 작업 자동화AI for Software Analysis and Security Tasks

AI로 소프트웨어의 동작과 취약점을 분석하고, 취약점 분석 등 보안 작업을 수행하는 에이전트를 개발합니다.We use AI to analyze software behavior and vulnerabilities, and develop agents for security tasks such as vulnerability analysis.

  • AI 기반 바이너리 분석AI-based binary analysis
  • 에이전트를 활용한 취약점 분석Agent-assisted vulnerability analysis
  • 보안 작업에서의 에이전트 행동과 성능 분석Agent behavior and performance on security tasks

Security for AI

에이전트 보안Agent Security

LLM 기반 에이전트의 취약점을 분석하고 안전한 활용을 위한 대응 방법을 연구합니다. 지시를 해석하고 도구를 사용하며 행동을 선택하는 과정에서 발생하는 보안 위험을 살펴봅니다.We analyze vulnerabilities in LLM-based agents and study ways to secure their use, examining risks as agents interpret instructions, use tools, and choose actions.

  • LLM 기반 에이전트의 취약점Vulnerabilities in LLM-based agents
  • 에이전트의 행동 편향과 지시 이행Behavioral bias and instruction compliance
  • 에이전트의 안전성 검증Assessing agent safety
