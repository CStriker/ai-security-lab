보안 작업 자동화Software Analysis
and Security Automation

AI를 활용해 소프트웨어의 동작과 취약점을 분석합니다. 세부 주제로 실행 파일(바이너리)을 분석하는 방법과 LLM 기반 에이전트가 취약점 분석 등 보안 작업을 수행하도록 하는 방법을 연구합니다.We use AI to analyze software behavior and vulnerabilities. Specific topics include analyzing executable binaries and enabling LLM-based agents to carry out security tasks such as vulnerability analysis.

에이전트의 작업 성공 여부, 행동 선택, 결과의 일관성을 함께 분석합니다. 이를 바탕으로 소프트웨어 분석과 취약점 점검에 활용할 수 있는 에이전트를 개발하는 것이 목표입니다.We analyze task success, action choices, and the consistency of results. Our goal is to develop agents that support software analysis and vulnerability assessment.

Security for AI

에이전트 보안Agent Security

LLM 기반 에이전트의 취약점을 분석하고 안전한 활용을 위한 대응 방법을 연구합니다. 에이전트가 지시를 해석하고 도구를 사용하며 외부 환경과 상호작용하는 과정에서 발생하는 보안 위험을 살펴봅니다.We analyze vulnerabilities in LLM-based agents and study ways to secure their use, examining risks as agents interpret instructions, use tools, and interact with external environments.

행동 편향과 지시 이행을 포함해 에이전트의 동작을 분석합니다. 입력이나 작업 환경이 달라져도 허용된 범위 안에서 안전하게 동작하는지 검증하는 방법에 관심을 두고 있습니다.We analyze agent behavior, including behavioral bias and instruction compliance. We are interested in verifying whether agents operate safely within their permitted scope as inputs and task environments change.

최근 연구Recent Research

CyBiasBench

김현준 교수가 공동 교신저자로 참여한 연구로, 사이버 공격 시나리오에서 LLM 에이전트의 행동 편향과 작업 수행 성능을 분석했습니다. 공격 성공률과 공격 유형 선택을 함께 측정하고, 지시 변경에 따른 행동 변화를 살펴봤습니다.Prof. Hyunjun Kim is a co-corresponding author of this study, which examines behavioral bias and task performance in LLM agents across cyber-attack scenarios. It measures attack success rates and attack-type choices, and analyzes behavioral changes under different instructions.
